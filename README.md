# Sparks & Bolt Electrical Services — Website Project

Web Development POE (Part 1: Building the Foundation)
Student: Roby | Student Number: ST10480499

## About This Project

This repository contains the website built for Sparks & Bolt Electrical Services, a
hypothetical small electrical contracting business based in Johannesburg, South Africa.
The project follows the three-part structure of the Web Development POE:

- Part 1 (current): HTML structure, inline CSS only, project planning and proposal.
- Part 2 (upcoming): External CSS styling, responsive design, UX refinement.
- Part 3 (upcoming): JavaScript functionality, form validation, SEO, and external service integration.

## Target Organisation

Sparks & Bolt Electrical Services — a small business offering electrical
installations, repairs, emergency callouts, and Certificate of Compliance (COC)
inspections to homeowners and small businesses across Johannesburg.

See docs/Proposal_1_Sparks_and_Bolt_Electrical.docx for the full approved Website
Project Proposal, and docs/Proposal_2_Braamfontein_Bake_House.docx for the alternate
proposal submitted for lecturer approval.

## Part 1 Learning Outcomes Covered

- Identified key advantages and success indicators of a business having a website.
- Sourced and planned free, legally licensed image assets (Unsplash).
- Created a well-organised file and folder structure for the website.
- Built semantic, standards-compliant HTML5 structure (header, nav, main, footer) across five linked pages.
- Applied inline CSS only, as required for Part 1.
- Linked all pages together via a consistent navigation system.

## How to View the Site

Open index.html in any modern web browser. All internal links are relative, so the
site will work locally or once hosted (e.g. via GitHub Pages).
